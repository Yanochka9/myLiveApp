# DetailLab — рилс из нескольких дублей (шаблон)

Отдельный формат от «ТикТок + сторис» в `../make_video.py`. Тот шаблон берёт **одно длинное видео**
и режет его на сторис с плашками тем. Этот — **рилс 40–55 с из многих коротких дублей + подсъёмов**,
с инфографикой. Эталон — рилс «Leopard, комплекс Максимальный» (27.10.2026).

Когда какой:
- одно видео, «история», «на сторис» → `../make_video.py` (SKILL detaillab-video);
- папка с дублями спикера (мужчина в центре) + подсъёмы, «рилс» → этот шаблон.

## Стиль

**Структура**
1. Хук 2–4 с: самая короткая цепляющая фраза. Открываем на подсъёме (разобранная машина),
   на ключевом слове — склейка на спикера, лёгкий наезд (1,36→1,46, **без замедления**).
2. Белая вспышка + щелчок `hit2` → сразу основной текст.
3. Из дублей берём лучшие, вырезаем сбивки, «так, заново», смех, повторы. Паузы между словами ≤ 0,35 с.
   Если фраза хука повторяется в основном тексте — второй раз её не ставим.
4. План меняется каждые 1–2 фразы: общий ↔ крупный (кроп из 4K, зум 1,42).
5. Подсъём — ровно на слово, которое он показывает; каждый один раз, в родной скорости.
   Короче фразы — возвращаемся на спикера. Из интернета не брать (кейс клиента).
6. Концовка ~3,4 с: общий кадр машины, яркий логотип (затемнение только под ним),
   «Пишите в Direct / Рассчитаем стоимость», «пр-т Дзержинского, 82А · Минск · 9:00–21:00 · без выходных».

**Графика (2D, золото `#D4AF37`)**
- Субтитры 1–2 слова, Montserrat ExtraBold, белые, ключевые слова золотом.
- Плашки: «Комплекс МАКСИМАЛЬНЫЙ», чек-лист «Что входит» (галочки на произнесении),
  «3 рабочих дня», этапы «Демонтаж → Оклейка → Монтаж». Всегда **ниже субтитров** (грудь/руки).
- Мемы не ставим без просьбы.

**Звук**
- Только `sfx/` (из видео клиента). Свои звуки не генерировать — слышно.
- `riser_hook` с первого кадра до вспышки, тихо (−31 дБ). `hit2` на вспышке. Прочие удары −18…−26 дБ.
- Музыка — трек клиента из Drive (папка музыки), `music/client.wav`, фоном: в паузах ~14 дБ ниже голоса,
  под голосом sidechain. В эталоне — id `19CPc_GsOVXSTSU7amm4dPYcFdRAPm0Eq` (Chill Coffee Flow).

**Цвет**
- По умолчанию — утверждённый `../assets/look.cube` (`grade_default.txt`), как в шаблоне историй.
  LUT подогнан под **сырое** декодирование iPhone-HDR (без перевода HDR→SDR) — не добавлять перед ним
  `grade_hdr_to_sdr.txt`, иначе цвет уедет.
- Любой другой стиль — сначала превью-картинкой рядом с эталоном, видео только после «да».
- Проверка: в серых G не выше (R+B)/2 больше чем на 2 (иначе зелень), без синевы.

## Сборка

ffmpeg (libass, lut3d, zscale), `pip install faster-whisper`.

1. Исходники в `src/IMG_*.MOV`, музыка в `music/client.wav`, `cp grade_default.txt grade.txt`.
2. `python3 tr.py medium <номера дублей>` → `words_medium.json`.
3. `python3 vad.py` → `segs.json` (диапазоны дублей в `vad.py` задать под ролик).
4. В `build.py`: `ORDER` (порядок дублей), `SH` (планы/подсъёмы на слова), `FACE` (где лицо в кадре).
   В `finish.py`: `FIX` (ошибки распознавания), плашки в `build_ass()`.
5. `python3 build.py && python3 finish.py` → `out/final.mp4`.
6. Проверить: распознать речь финала (целиком, без сбивок), раскадровка, уровни звука.

`example-leopard-reel/` — расшифровка и сегменты эталона (образец формата).

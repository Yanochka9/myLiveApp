# DetailLab — рилс из нескольких дублей (шаблон)

Отдельный формат от «ТикТок + сторис» в `../make_video.py`. Тот шаблон берёт **одно длинное видео**
и режет его на сторис с плашками тем. Этот — **рилс 40–55 с из многих коротких дублей + подсъёмов**,
с инфографикой. Эталон — рилс «Leopard, комплекс Максимальный» (27.10.2026).

Когда какой:
- одно видео, «история», «на сторис» → `../make_video.py` (SKILL detaillab-video);
- папка с дублями спикера (мужчина в центре) + подсъёмы, «рилс» → этот шаблон.

## Перед монтажом — уточнить у клиента
- **Нужен ли хук** в этом ролике и какой фразой. Не во всех роликах он есть — не придумывать самому.
- **Нужен ли мем** и куда. Может быть, может не быть — решает клиент; можно предложить место.
- Модель авто, текст финальной плашки/призыва, есть ли кадр «после».

## Стиль

**Структура**
1. Хук 2–4 с (**только если клиент подтвердил хук**): самая короткая цепляющая фраза. Открываем на подсъёме (разобранная машина),
   на ключевом слове — склейка на спикера, лёгкий наезд (1,36→1,46, **без замедления**).
2. Белая вспышка + щелчок `hit2` → сразу основной текст.
3. Из дублей берём лучшие, вырезаем сбивки, «так, заново», смех, повторы. Паузы между словами ≤ 0,35 с.
   Если фраза хука повторяется в основном тексте — второй раз её не ставим.
4. План меняется каждые 1–2 фразы: общий ↔ крупный (кроп из 4K, зум 1,42).
5. Подсъём — ровно на слово, которое он показывает; каждый один раз, в родной скорости.
   Короче фразы — возвращаемся на спикера. Из интернета не брать (кейс клиента).
6. Концовка ~3,4 с: общий кадр машины, яркий логотип (затемнение только под ним),
   «Пишите в Direct / Рассчитаем стоимость», «пр-т Дзержинского, 82А · Минск · 9:00–21:00 · без выходных».

**Графика (2D, золото `#D4AF37`) — обязательная часть раскадровки**
- В каждом ролике есть 2D-графика: иконки, рисованные элементы, фигурки, стрелки, обводки
  дефектов, инфографика. Планировать её вместе с раскадровкой: на каждый смысловой блок —
  какой элемент появляется и на каком слове (а не добавлять в конце «если останется место»).
- Примеры: иконки деталей (фара, зеркало, дверь) у пунктов списка, стрелка/обводка на детали в подсъёме,
  значки-цифры, таймер/календарь у срока, схема авто с подсвеченными зонами оклейки.
- Элементы появляются мягко (скейл/фейд 150–250 мс) с тихим звуком из `sfx/`, без резких анимаций.
- Субтитры 1–2 слова, Montserrat ExtraBold, белые, ключевые слова золотом.
- Плашки: «Комплекс МАКСИМАЛЬНЫЙ», чек-лист «Что входит» (галочки на произнесении),
  «3 рабочих дня», этапы «Демонтаж → Оклейка → Монтаж». Всегда **ниже субтитров** (грудь/руки).
- Мем — только если клиент подтвердил (см. «уточнить»).

**Звук**
- Только `sfx/` (из видео клиента). Свои звуки не генерировать — слышно.
- `riser_hook` с первого кадра до вспышки, тихо (−31 дБ). `hit2` на вспышке. Прочие удары −18…−26 дБ.
- Музыка — трек клиента из Drive (папка музыки), `music/client.wav`, фоном: в паузах ~14 дБ ниже голоса,
  под голосом sidechain. В эталоне — id `19CPc_GsOVXSTSU7amm4dPYcFdRAPm0Eq` (Chill Coffee Flow).

**Цвет**
- По умолчанию — утверждённый `../assets/look.cube` (`grade_default.txt`), как в шаблоне историй.
  LUT подогнан под **сырое** декодирование iPhone-HDR (без перевода HDR→SDR) — не добавлять перед ним
  `grade_hdr_to_sdr.txt`, иначе цвет уедет.
- Любой другой стиль — сначала превью-картинкой рядом с эталоном, видео только после «да».
- Проверка: в серых G не выше (R+B)/2 больше чем на 2 (иначе зелень), без синевы.

## Сборка

ffmpeg (libass, lut3d, zscale), `pip install faster-whisper`.

1. Исходники в `src/IMG_*.MOV`, музыка в `music/client.wav`, `cp grade_default.txt grade.txt`.
2. `python3 tr.py medium <номера дублей>` → `words_medium.json`.
3. `python3 vad.py` → `segs.json` (диапазоны дублей в `vad.py` задать под ролик).
4. В `build.py`: `ORDER` (порядок дублей), `SH` (планы/подсъёмы на слова), `FACE` (где лицо в кадре).
   В `finish.py`: `FIX` (ошибки распознавания), плашки в `build_ass()`.
5. `python3 build.py && python3 finish.py` → `out/final.mp4`.
6. Проверить: распознать речь финала (целиком, без сбивок), раскадровка, уровни звука.

`example-leopard-reel/` — расшифровка и сегменты эталона (образец формата).

## Пример 2: `repaint/` — «Крашеный элемент и плёнка» (02.11.2026)
Один дубль спикера (IMG_2509 + IMG_2510) без хука, подсъёмы чёрной машины (2512–2520). Что добавлено к шаблону:
- **Текст за спиной** в первые секунды («ВТОРИЧНЫЙ ОКРАС?») — маска спикера MODNet (`matte.py`,
  модель `Xenova/modnet` onnx, Apache-2.0, качается в `repaint/models/`).
- **Псевдо-3D «пирог» ЛКП** (металл → грунт → краска → лак → плёнка), на «вторичном окрасе» краска → «перекрас»,
  на «подорвать» — плёнка отрывается вместе с лаком (`gfx.py`, PIL, рисуется по кадрам поверх видео).
- **Мем** «МОИ ПОЛНОМОЧИЯ — ВСЁ» после «Конечно нет»: стоп-кадр, ч/б, наезд, музыка проваливается (своя отрисовка, без чужих клипов).
- Иконки «где / за сколько / как», таймлайн «скол → коррозия → перекрас → оклейка», плашки, финал с логотипом и адресом.
- Речь ускорена ×1,08 (`SP` в build.py), вырезаны только повторы/паразиты.
Сборка: `python3 vad.py && python3 build.py && python3 matte.py 6.6 && python3 gfx.py --part i 4 (×4) → concat → python3 finish.py`.
Превью кадров графики: `python3 gfx.py 12.0 20.5` → `out/prev_*.jpg`.
- **Правки клиента (v2):** мем убран; шумодав `arnndn` (sh.rnnn, mix 1.0) + мягкий гейт; **вся графика в безопасной зоне**
  (ширина ≤ 720 px по центру, y 250–1560, плашки Inter Black/Oswald, рамка 2 px) — широкие плашки обрезались в Reels;
  объёмные 3D-буквы за спиной (экструзия + градиент + блик); на подсъёме капота (2516) — пунктир по шву и метки
  «ОРИГИНАЛ — заводской блеск / ПЕРЕКРАС — глянец без блеска» (крыло слева родное, капот справа крашеный).
  Кусок речи не обрывать на whisper-таймкоде — проверять энергию: «делают так же» звучало до 60.95 с, а не 60.36.
- **Цвет:** `repaint/grades/*.txt` (1-я строка — HDR→SDR до кропа, 2-я — цвет). `v2_refs` — кривая, снятая с примеров клиента
  (Drive «яна детейлинг пример»), без перенасыщения кожи. Выбранный копируется в `repaint/grade.txt`.

### Цвет — всегда `../assets/grade_client.txt` (утверждён 03.11.2026)
Для любого нового рилса: `cp ../assets/grade_client.txt <проект>/grade.txt` (замена `ASSETS/` → путь к assets делается в build.py,
как в `repaint/build.py`: строка 1 — HDR→SDR до кропа, строка 2 — цвет). `grade_default.txt`/look.cube — устарело.
Как снят: кривая под примеры клиента + её правка в CapCut, перенесённая попиксельно: её скриншот из CapCut ↔ тот же
кадр нашего ролика без правки → поканальные кривые r/g/b. Запись экрана искажает цвет — по ней не подгонять.

### Адаптивный цвет (с 03.11.2026)
Свет в исходниках разный, а результат должен быть один: `../autograde.py` подравнивает каждый клип под эталон
(`../assets/grade_ref.json`: баланс белого, яркость по перцентилям, насыщенность), потом общий стиль `grade_client.txt`.
В build.py рилса: `AUTO = True` и `gpre_for(src)` вместо общего `GPRE` (см. `repaint/build.py`).
Кривые — только `interp=pchip`: обычная (natural) у пересвеченных лиц перелетает за белый и даёт зелень.

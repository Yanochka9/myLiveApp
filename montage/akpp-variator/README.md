# АКПП Драйв — «Сам поменял масло в вариаторе»

Скрипты, которыми собран ролик (53 с, 1080×1920, 30 fps). Пути к исходникам и ассетам заданы в `edl.py` (`SP`) — при повторном использовании поменяйте их.

Порядок сборки:
1. `python3 render_shots.py` — склейка, перебивки, приближения/отдаления, цветокор, ЧБ-хук → `base.mp4`.
2. `python3 -c "import edl,json;print(json.dumps(edl.gfx_timeline()))" > gfx.json && node render_gfx.js` — графика (REC, вспышки, обводки, схема вариатора, ×20, адрес, финальная плашка).
3. `python3 subs.py` — субтитры по слову, акценты красным.
4. `python3 audio.py` (и `--no-music`) — голос, SFX на переходах, гул на хуке, фон мастерской, музыка.
5. Финал: overlay графики + `ass=subs.ass` + звук, `crf 20`.

Звуки и стоковые кадры — Mixkit (бесплатная лицензия): SFX 790, 1430, 2299, 166, 1489/1490/1492, 1143, 2595, 1457, 3005, 2568, 1486, 2749; видео 13260, 41937, 33324; музыка-заглушка 267 «Trap Hamza».

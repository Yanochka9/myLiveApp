# АКПП Драйв — рилсы из нескольких дублей

Пайплайн для роликов, где синхрон собран из нескольких файлов-дублей (у вариатора был один длинный файл). Стиль — строго по `../BRIEF.md`.

| Файл | Ролик |
|---|---|
| `vibration.py` | Ролик 1. Ответ на вопрос: «Т5 автомат, вибрация при разгоне до 4-й» |
| `lifan.py` | Ролик 2. История Lifan X60: «А они говорили, что китайцы х**ня» |
| `equinox.py` | Ролик 3. Chevrolet Equinox: «Один удар в колесо, один потёкший сальник…» |
| `dq400e.py` | Ролик 4. DQ400E: «Очередной биток из Америки» |

Общий движок — `lib.py`, графика — `gfx.html` + `render_gfx.cjs`.

## Как устроен конфиг ролика

- **`HOOK`** — файл и отрезок хука. Хук ведётся наездом камеры: `zoom_from` → `zoom_to`, к точке `face`.
- **`PHRASES`** — фразы синхрона: `(файл, начало, конец, опции)` во времени исходника.
  - Паузы внутри фразы режутся автоматически по громкости (`silencedetect −44 dB`).
  - Перед речью остаётся 0,05 с, после — 0,11 с, чтобы не съедать окончания слов.
  - В опциях задаётся центр кропа для крупного плана 1,35×.
- **`BROLL`** — перебивки: `(файл фразы, от, до, клип, вход в клип, motion, опции)`.
  - Окна задаются во времени исходника, движок переводит их в выходное время.
  - Опции:
    - `cx` — центр кропа стока;
    - `scale`;
    - `slow` — замедление коротких подсъёмов.
- **`gfx(R)`** — события графики:
  - `header` — плашка-заголовок;
  - `label` — подпись;
  - `ellipse` — обводка дефекта;
  - `brackets` — рамка-уголки;
  - `counter` — счётчик;
  - `interval` — старое значение зачёркнуто, новое ниже;
  - `checklist` — нумерованный список;
  - `leak` — капли и лужа масла;
  - `garage` — схема въезда в гараж под уклоном;
  - `gears` — вибрация по передачам;
  - `question` — пузырь вопроса;
  - `address` — плашка с адресом;
  - `flash` — вспышка-переход.

  `R.m(файл, t)` переводит время исходника в выходное.
- **`sfx(R)`** — звуки из `../assets/sfx/`, громкости как в брифе.
- **`BLEEP`** — где заглушить голос. Мат в хуке Лифана закрыт чириканьем птички: Mixkit SFX #23 «Little bird calling chirp», громкость 0.16.
- **`END_Q`** — вопрос на финальной плашке.
- **`PHRASEFIX` / `ACCENT` / `HIDE`** — правки текста субтитров, красные слова, окна без субтитров (где тот же текст уже показан графикой).

## Субтитры

Смонтированная дорожка голоса заново распознаётся `faster-whisper` large-v3. Так тайминги слов точные, а пропавшие слова на склейках сразу видны. Кэш лежит в `build/<ролик>/voice_words_<hash>.json`.

## Запуск

Исходники лежат в `$AKPP_SP/src/{reels,broll}`, стоки — в `$AKPP_SP/stock`. Дальше:

```
python3 lifan.py plan     # монтажный лист
python3 lifan.py all      # шоты → субтитры → графика → микс → финал (без музыки)
python3 lifan.py post     # всё, кроме рендера шотов
python3 lifan.py shots 6 42   # перерендер отдельных шотов
```

Результат — `$AKPP_SP/out/<ролик>_nomusic.mp4` и контактный лист `build/<ролик>/contact.jpg`.

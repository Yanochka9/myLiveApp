# АКПП Драйв — «DP0 / AL4 уходит в аварию» (вопрос подписчика)

Собран по `../BRIEF.md` на основе скриптов `../variator/`. 48 с (45 с + плашка 3 с), 1080×1920, 30 fps.
Исходник — IMG_2730.MOV (вертикальный 4K HLG): мастер читает вопрос с телефона и отвечает. Пути — `SP` в `edl.py`.

Структура: хук 4 с (карточка «Вопрос подписчика», счётчик 0→1000 КМ, «10–20 КМ/Ч», без музыки) → вспышка →
контекст (плашка DP0 / AL4) → вспышка → ответ: схема гидроблока (утечка давления, манометр, ЭБУ «аварийный режим»),
три причины списком 1-2-3 с рамками на перебивках, «продукты износа» → «ДИАГНОСТИКА БЕСПЛАТНО» → адрес → финальная плашка «А у вас была такая проблема с DP0?».
Из 6 дублей призыва взят последний (127–137 с). Склейки только в паузах, проверено повторным распознаванием.

Сборка:
1. `python3 render_shots.py` → shots + `build/shots/list.txt`, затем concat → `base.mp4`.
2. `python3 -c "import edl,json;print(json.dumps(edl.gfx_timeline()))" > $SP/build/gfx.json && GFX_OUT=$SP/build node render_gfx.cjs`.
3. `python3 subs.py` (DP0 / AL4 латиницей, «-» скрывает слово, которое уже показано графикой).
4. `python3 audio.py` и `python3 audio.py --no-music` — музыка ставится на 13,5 дБ ниже измеренного голоса.
5. Финал: overlay графики + `ass=subs.ass`, звук `volume=12.8dB` + лимитер, `crf 20` → −15,4 LUFS.

Подсъёмы клиента: 8842 (6 с, 26 с, 36 с), 9190, 9186, 0784. Стоки Mixkit: 15056 (щуп), 72 (руль), 13270 (механик под капотом).
Музыка-заглушка Mixkit 267. Звуки — `../assets/sfx/`.

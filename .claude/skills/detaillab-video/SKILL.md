# Монтаж роликов DetailLab по шаблону

Шаблон и код: `montage/detaillab/` (README там же). Эталон — `examples/leopard.json`.
Отвечать пользователю по-русски, коротко. Готовые файлы отправлять через SendUserFile.

## Что пользователь присылает
- Ссылку на видео в Google Drive (или на папку + «последнее, загруженное в HH:MM»).
- По желанию: что написать в финальной плашке (цена, срок, «Напиши +»), модель авто.
Файлы в Drive открыты по ссылке — качать `curl` через `drive.usercontent.google.com` (так делает `make_video.py`).
ID файла в папке найти через `mcp__Google_Drive__search_files` (`parentId = '<папка>'`, сортировать по `createdTime`).

## Порядок работы
1. Скопировать `examples/leopard.json` в `examples/<name>.json`, вписать `name`, `source_drive_id`.
2. `python3 -I make_video.py prep examples/<name>.json` — скачает, сделает proxy 1080×1920,
   транскрипцию (`words.json`, печатает текст с таймкодами) и листы кадров `sheet_XX.jpg` (каждые 0.5 с с таймкодом).
3. Прочитать транскрипт и листы кадров, составить `edl` — список `[a_start, a_end, v_start|null, zoom, part, plate]`:
   - **Хук первым**: самая цепляющая фраза (страх/экспертиза/цифра) ЦЕЛИКОМ, 6–12 с, plate `"hook"`, part 1.
   - Дальше всё по порядку, **фразы целиком** — не резать слова и смысл. Паузы > 0.5 с скрипт режет сам.
     Убрать только вступления-«воду» («так, суббота, рабочая атмосферка»).
   - **Развороты камеры, палец в кадре, смаз** — закрыть: `v_start` = время чистого плана машины (голос остаётся).
   - Последний кусок: конец = последнее слово + **1.0 с** (иначе слово обрежется), затем заставка.
   - `zoom` 1.0 / 1.04–1.08 чередовать на склейках; `part` — номер сторис (10–20 с каждая, по смысловым блокам).
4. `plates`: по плашке на тему, 2 строки ПРОПИСНЫМИ (верх белый, низ золотой), коротко. Последняя — призыв
   («СЛОЖНЫЙ АВТО? / НАПИШИ «+» В ДИРЕКТ» или что попросили). `fix_words` — ошибки распознавания.
5. `python3 -I make_video.py build examples/<name>.json` (~10–15 мин, запускать в фоне).
6. Проверить перед отправкой: листы кадров финала, первый кадр (плашка видна), вспышку после хука,
   **распознать речь в последних 6 с** финала — последнее слово целиком, длина аудио = длине видео.
7. Отправить TikTok + Story_N. Закоммитить конфиг `examples/<name>.json` (правило репо — сразу в main).

## Утверждённые решения (не менять без просьбы)
- Цвет — `assets/look.cube` (подогнан под CapCut-референсы: темнее, холоднее, глубокие тени). Не высветлять.
- Плашки — тёмные с золотой рамкой, ПОД субтитрами. Субтитры — строчные белые Montserrat, ниже лица.
- Без стабилизации (давала смазанную полосу по краю). Без шумодава (голос становился тихим).
- Вспышка + «вжух» между хуком и основной частью; мягкие вспышки + щелчки на смене плашек и на заставке.
- Музыка — из папки Drive «музыка и звуки», тихо, но слышно (music_vol ≈ 0.22), без вокала.
- Экспорт ~9 Мбит/с (156 МБ не открывался в просмотрщике), длина ТикТока — сколько нужно для смысла.

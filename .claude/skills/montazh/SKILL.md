# Монтаж ролика по шаблону video-kit («шаблон Трейлблейзер», Chevrolet Trailblazer)

Если пользователь пишет «как трейлблейзер», «шаблон трейлблейзера», «как в Trailblazer» — это этот шаблон.

Набор лежит в `video-kit/` (инструкция для людей — `video-kit/README.md`, пример проекта — `video-kit/projects/trailblazer.json`).
Все команды запускать из `video-kit/`: `python3 make.py projects/<имя>.json <команда>`.

## Эталон рилсов Белавто — `video-kit/projects/top3.json` (утверждён пользователем)

Все рилсы этого проекта делать как `top3.json`, меняя только графику, картинки, цвета/шрифты и подставки под новый ролик:
3D-марка над 3D-моделью и год сразу под ними (блок в верхней половине кадра, не на машине и не на лице); значок места `rank`;
шторка `wipe` на смене блоков; золотой (`gold`) год и счётчик пробега с полосой и тихим тиканьем; фишки — плашки
в верхней части кадра (на потолке, не на машине) и фото-карточки `photo` с деталями; обводки `circle`, дудлы `icon`;
над ценой — две разведённые плашки «В КРЕДИТ» и «БЕЗ ПЕРВОГО ВЗНОСА», «BYN / мес» справа от цифры, не на лице;
цветокор Refive (`lut`) + тема; мягкий свуш `swish_soft.wav` на стыках, щелчки на фото-карточках.

## Правила ролика (не нарушать без прямой просьбы)

- Никаких сгенерированных звуков. Звуки переходов (`sfx`) — только если пользователь просит, и только из его пакета
  (Белавто: `assets/sfx/belavto_whoosh.wav` на смене блоков, `belavto_click1–5` на фото-карточках, тихо).
- Голос не обрабатывать: только постоянное усиление на дубль (делает `build_audio`). Без EQ, компрессии, шумодава.
- Цветокор лёгкий и нейтральный; цвет бренда — в графике (`theme`), не в картинке.
- Субтитры — строго по голосу. Цифры на плашках — из сценария; если голос и сценарий расходятся, сказать об этом пользователю.
- Длина 30–45 с, вертикаль 1080×1920, 30 fps.

## Порядок работы

1. **Среда.** `bash setup.sh` (если `import bpy` падает). Drive должен быть доступен по сети
   (`drive.google.com`, `drive.usercontent.google.com` в разрешённых доменах окружения), папка — «доступ по ссылке».
2. **Проект.** Скопировать `projects/trailblazer.json` в `projects/<имя>.json`, поменять `name`, `sources.drive_folder`,
   `output`, `music` (`search` или `file`), тему по просьбе пользователя (палитры — в README).
3. **Исходники.** `fetch`, затем `analyze`: печатает расшифровку каждого клипа со временем слов и пути к раскадровкам
   (`work/<имя>/sheets/_page*.jpg`). Смотреть ТОЛЬКО страницы раскадровок (по 6 клипов на картинке), не отдельные кадры.
   Готовые ролики-референсы в папке (обычно `.mp4` без сырого звука) — для стиля, в монтаж не брать.
4. **Склейки.** По расшифровке и сценарию заполнить `aroll` (дубли с речью по порядку; `in` чуть раньше первого слова,
   `out` в паузе после последнего — паузы видны по словам) и `cutaways` (перебивки поверх речи под то, о чём говорят).
   Длина `cutaways` ≤ длины исходника минус `src`.
5. **Вставки.** `elements`: время привязывать к словам (`"w:слово"`), не к секундам — так меньше пересчётов.
   3D: `rise` за ведущей для названия модели и большой цифры (`"layer": "behind"`), `badge` для комплектации,
   `slab` для цены, `pin` для адреса, `spin` на финальной карточке. Остальное — `pill`/`callout`/`label`.
   Фишки машины можно показывать фото-карточкой `photo` (кадр детали из исходника) поверх ведущей вместо полноэкранной перебивки.
   Готовые ролики-референсы Белавто (Trailblazer, Palisade, Changan X5) — папка Drive `1pCyTWFiMaofJ8B49blxVyB0CIjJhiigv`;
   оттуда идеи: шторка `wipe`, обводка `circle`, дудлы `icon`, счётчик `counter`, плашки «В КРЕДИТ · БЕЗ ПЕРВОГО ВЗНОСА» над ценой.
   Ролики должны отличаться друг от друга: менять `theme` (цвет, шрифты), анимации вставок и `grade` (пример «Шампань» — `projects/top3.json`).
   Позиции: текст «за ведущей» — так, чтобы голова перекрывала только низ букв; плашки — в верхней половине кадра;
   субтитры на `y≈1330`, плашки туда не ставить.
6. **Проверка.** `check` — обязательно перед `render`: все элементы и субтитры внутри безопасной зоны TikTok / Reels
   (верх 210 px, низ 1480 px, колонка кнопок справа x > 930 на y 820–1560) и ничего не закрывает лицо ведущей.
   Исправлять, пока не будет «всё внутри» и «лицо свободно». Затем `subs` (фразы субтитров), один `preview` на 10–14 ключевых моментов (каждый новый 3D-элемент,
   каждый callout, финальная карточка) и посмотреть один `sheet.jpg`. Править конфиг, повторять превью только для
   изменённых моментов.
7. **Финал.** `render` в фоне (`run_in_background`), ждать уведомления, не опрашивать. Проверить `ffprobe` (длительность,
   1080×1920) и громкость в логе (`mix: ~-17 LUFS`), отправить файл пользователю.

## Экономия времени и лимитов

- 3D рендерится на CPU (~15–25 с/кадр). Тексты и цвета 3D менять до финала; одинаковые 3D-элементы берутся из `cache3d/`.
- Не смотреть отдельные кадры исходников — только страницы раскадровок и `preview/sheet.jpg`.
- Не проверять прогресс фонового рендера без нужды; не делать повторный `render` ради мелочей — сначала `preview`.
- Маски (ISNet) считаются только для отрезков с `"layer": "behind"`. Артефакты маски на фоне убирать
  прямоугольниками в `mask_cleanup` (координаты в кадре 1080×1920).

## Частые проблемы

- iPhone снимает в HDR (HLG) — тонмаппинг включается автоматически по метаданным клипа.
- Whisper растягивает первое слово дубля на тишину — `analyze` это исправляет; если субтитр появился раньше речи,
  поправить первое слово в `work/<имя>/words/<клип>.json`.
- Длинные фразы субтитров сами уменьшаются под ширину; ошибки распознавания — в `subtitles.replace`.
- Трек из библиотеки CapCut/TikTok часто есть на SoundCloud у автора (`music.search`); YouTube из облака требует вход.

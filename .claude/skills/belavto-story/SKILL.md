# Сторис «мини-обзор авто» для Белавтоцентра

Утверждённый стиль (не менять без просьбы пользователя):
- цвет: HDR iPhone → SDR (hable), холоднее и спокойнее: `eq=saturation=0.8:contrast=1.06` + холодный colorbalance (в `prep.py`);
- тишина в начале и между клипами срезается автоматически;
- шапка сверху: красная плашка (необязательная) → «Модель Год» → «Цена/мес» → белая плашка «без первого взноса»;
- субтитры фразами, Inter ExtraBold, белые, ключевые слова (*без первоначального взноса*, *цена*) жёлтым;
- финальный экран 2.8 с: кадр размывается, «Хотите увидеть вживую? / Запишитесь на тест-драйв / Пишите «КОДОВОЕ СЛОВО» в директ / Белавтоцентр · цена»;
- звук: голос, очень тихая музыка (≈21 дБ ниже голоса), мягкий тап на финальной плашке (assets/tap.wav, громкость 0.5).

## Порядок работы

1. **Исходники.** Если дана ссылка на папку Google Диска — список файлов через `mcp__Google_Drive__search_files` с `parentId = '<id папки>'` (проверь `nextPageToken`). Скачивание:
   `curl -sSL -o FILE "https://drive.usercontent.google.com/download?id=<ID>&export=download&confirm=t"`.
   Сделай кадры каждого файла (`ffmpeg -vf fps=1,scale=240:-2,tile=8x4`), чтобы понять, какие файлы к какой машине относятся и в каком порядке (обычно: общий план у машины → салон/проходка → финал у машины с ценой). Если не очевидно — спроси.

2. **Спроси у пользователя одним сообщением, если это не сказано:**
   - машина дня или нет? Если нет — предложи 1–2 плашки под машину («Семейный вариант», «Без пробега», «Для города», «Экономичный дизель», «Яркий хэтчбек»…) или вариант без плашки;
   - кодовое слово для директа (по умолчанию — модель латиницей, напр. CIVIC).
   Модель, год и цену бери из озвучки; если в голосе их нет — спроси.

3. **Подготовка:** `python3 -I scripts/prep.py WORKDIR clip1 clip2 ...` (в порядке монтажа). Нужен `faster-whisper` (`pip install faster-whisper`, если нет). Скрипт печатает слова с таймингами и пишет `WORKDIR/words.json`, `WORKDIR/sheet.jpg`.

4. **Конфиг** `WORKDIR/config.json`. Субтитры составь сам из `words.json`: фразы по 2–4 слова, исправь ошибки распознавания (марки латиницей: Honda Civic, Changan; «В продаже», «коробке передач», «без первоначального взноса»), длинные строки переноси `\n`, выделение `*так*`. Фразы не должны пересекаться по времени; последняя заканчивается на `main_dur`.
   ```json
   {
    "workdir": "WORKDIR",
    "out": "WORKDIR/Honda_Civic_2006.mp4",
    "badge": "Машина дня",
    "title": "Honda Civic 2006",
    "price": "500 BYN/мес",
    "pill": "без первого взноса",
    "cta_word": "CIVIC",
    "cta_footer": "Белавтоцентр · 500 BYN/мес без взноса",
    "music": "PATH/music.wav",
    "music_offset": 5,
    "subs": [
     {"t": "В продаже появилась", "s": 0.0, "e": 1.12},
     {"t": "вы можете\n*без первоначального взноса*", "s": 14.23, "e": 15.97}
    ]
   }
   ```
   `badge: null` — без красной плашки. `pill: null` — если машина не продаётся без взноса.

5. **Музыка.** Папка «музыка и звуки» на Диске: id `1ZbAan11DVIC-36TzhXd-72B4k7EUs8h6`. Трек по умолчанию — `copy_8AEA83FF-6912-4DDA-B9E4-929F03F5E58A.mov` (id `19CPc_GsOVXSTSU7amm4dPYcFdRAPm0Eq`), начало с 5-й секунды. Скачай и вытащи звук: `ffmpeg -i music.mov -vn -ar 48000 -ac 2 music.wav`. `copy_B2B212EF…` — это видео-переписка со звуками, не музыка.

6. **Сборка:** `python3 -I scripts/render.py WORKDIR/config.json`. Посмотри `WORKDIR/final_sheet.jpg` (шапка, субтитры, финальный экран), затем отправь ролик через `SendUserFile` (display: render). Файлы клади в scratchpad.

7. Правки пользователя вноси точечно, только то, что просили. Не меняй остальное оформление.

## Ошибки, которые уже были — не повторять

- **Цвет — только холодный грейд из `prep.py`.** Пользователю нравится холодная спокойная картинка. Однажды на «слишком голубой, было насыщеннее» грейд заменили на тёплый и насыщенный (`saturation=1.2`, почти без синего) — получилось «слишком яркий свет, нет холодной картинки». Если просят поправить цвет — меняй грейд на маленький шаг (например, `saturation` 0.8 → 0.9 или чуть меньше синего), холодную основу оставляй. Перед сборкой покажи кадр «было / стало» и дождись ответа; новый грейд не применяй ко всем роликам сразу.
- **«Музыку погромче» — заметно громче, и проверь замером.** По умолчанию музыка под голосом получается ≈29 дБ тише голоса (громкость 0.06 и приглушение под голос в `render.py`), её слышно только на финальном экране. Умножение `music.wav` на 1.6 (+4 дБ) ничего не дало: «музыки не слышно, только в конце». Если просят громче — поднимай саму громкость музыки в миксе (порядок 0.2–0.3) и/или ослабляй приглушение под голос. Перед отправкой отрендери отдельно дорожку голоса и музыки (как в `render.py`) и сравни громкость (`ebur128`): под голосом музыка должна быть примерно на 15–18 дБ тише, не на 25+. Не пиши «музыка громче», пока не проверил цифрами.
- Не меняй утверждённое оформление по своей инициативе «к лучшему». Если что-то кажется спорным — спроси, а не переделывай.

## Статичные сторис-продолжения

К каждому смонтированному сторис-ролику Белавто, у которого в задаче планера есть раздел **«Статичная сторис»** (или если пользователь просит), сразу делай статичный кадр-продолжение и отправляй вместе с роликом. Это относится и к «машине дня», и к говорящим сторис (продать авто, кредит, доверие, живые истории).

- Сборка: `python3 -I scripts/static.py WORKDIR/static.json` → `static.png` (для публикации) и `static_preview.png` (с отмеченной зоной стикера — для проверки, не публиковать).
- Фон — исходник ролика без вшитых субтитров (`bg_time` — нужная секунда) или скрин сайта/каталога. `blur: true` — для опросов и вопросов, `blur: false` — когда фон должен читаться (калькулятор, машина, три авто в подборке).
- **Без красной плашки** (`"badge": null`): пользователю она на картинках «не впопад». Текст — 2–3 строки, ключевое слово `*жёлтым*`.
- Зона стикера (y 1080–1440) остаётся пустой: опрос, вопрос, викторину, ссылку или «Написать» пользователь ставит сам в Instagram — вшитый стикер не кликается. В подписи к файлу напиши, какой стикер и с какими вариантами ответа поставить.

```json
{"bg": "WORKDIR/clip_1.mov", "bg_time": 3.0, "blur": true, "badge": null,
 "title": "Продавали машину\nсами?", "sub": "Как прошло — *честно*",
 "sticker": "poll", "out": "WORKDIR/static.png"}
```

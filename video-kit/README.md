# Шаблон монтажа роликов про авто («шаблон Трейлблейзер»)

Собирает вертикальный ролик 1080×1920 по одному файлу проекта (`projects/<имя>.json`):
склейки дублей, перебивки, субтитры с подсветкой слова, 2D-плашки, настоящие 3D-элементы (Blender),
текст «за» ведущей и машиной по маске, лёгкий цветокор, музыка под голосом и финальная карточка.

Голос не обрабатывается: только одно постоянное усиление на дубль, чтобы дубли звучали одинаково громко.
Звуков переходов и эффектов нет.

Пример — `projects/trailblazer.json` (ролик про Chevrolet Trailblazer).

## Самый простой способ

Откройте сессию Claude Code в этом репозитории и напишите:

```
/montazh вот папка с исходниками: <ссылка на Drive>, вот сценарий: ... Цвета — синие, субтитры жёлтые.
```

Claude сам сделает проект по шаблону, покажет превью кадров и соберёт ролик.

## Вручную

```bash
cd video-kit
bash setup.sh                                     # один раз в новой среде: зависимости
cp projects/trailblazer.json projects/new_car.json   # правим под новый ролик
python3 make.py projects/new_car.json fetch       # скачать исходники с Drive (+ музыку по поиску)
python3 make.py projects/new_car.json analyze     # расшифровка речи + раскадровки всех клипов
python3 make.py projects/new_car.json subs        # проверить субтитры
python3 make.py projects/new_car.json check       # безопасная зона TikTok / Reels + ничего не закрывает лицо
python3 make.py projects/new_car.json preview 1.5 8 20 33   # отдельные кадры -> work/new_car/preview/sheet.jpg
python3 make.py projects/new_car.json draft       # быстрый черновик всего ролика
python3 make.py projects/new_car.json render      # финал -> out/new_car.mp4
```

Папки `work/`, `out/`, `cache3d/` не попадают в git: там исходники, кэш и готовые ролики.
Уже отрендеренные 3D-элементы с теми же текстом и цветами берутся из `cache3d/` и не рендерятся заново.

## Что менять в проекте

### Цвета — `theme`

| Поле | Что красит |
|---|---|
| `accent`, `accent_light` | основные плашки (градиент), подсветка слова в субтитрах, вспышки |
| `dark`, `light` | тёмные и светлые плашки |
| `link` | сайт на финальной карточке |
| `flash` | цвет мягкой вспышки на переходах |
| `glow`, `vignette` | свечение в углу кадра и затемнение краёв (0 — выключить) |
| `3d.front`, `3d.side` | лицевая сторона и бока 3D-букв, значков, метки |
| `3d.white`, `3d.dark` | текст на 3D-плашке, диск 3D-значка |
| `on_accent`, `on_light` | цвет текста на акцентных и на светлых плашках (для светлых акцентов вроде золота — тёмный) |
| `paper` | рамка фото-карточек `photo` |
| `fonts` | пути к шрифтам (`black`, `xbold`, `bold`, `semibold`, `black_italic`); свои шрифты — в `assets/fonts/` (есть Manrope) |

Готовые палитры:

```json
"красная":  {"accent": "#E20E2A", "accent_light": "#FF3448", "dark": "#280608", "3d": {"front": "#ED2030", "side": "#700012"}}
"розовая":  {"accent": "#FF3E9A", "accent_light": "#FF7BBE", "dark": "#2A0818", "3d": {"front": "#FF5AAE", "side": "#7A0F45"}}
"синяя":    {"accent": "#1E5BFF", "accent_light": "#4C82FF", "dark": "#0A1430", "3d": {"front": "#2F6BFF", "side": "#0B1F66"}}
"золото":   {"accent": "#C9A23F", "accent_light": "#E8C76A", "dark": "#1C1608", "3d": {"front": "#E2B84E", "side": "#6B4E12", "metallic": 0.8}}
"шампань":  см. projects/top3.json — золото + on_accent/on_light тёмные + шрифт Manrope + фильтр Refive 70 %
```

### Цветокор — `grade`

`gamma`, `contrast`, `saturation`, `warmth`, `cool_shadows` и фильтр `lut` (файл `.cube`, например `assets/luts/refive_light.cube` — «как Refive»)
с силой `lut_mix` от 0 до 1.

### Субтитры — `subtitles`

`size`, `y` (высота на экране), `color`, `highlight` (цвет подложки активного слова: `accent` или `#HEX`),
`highlight_text`, `mode` (`karaoke` — подсветка бежит по словам, `first` — подсвечено первое слово, `none`),
`uppercase`, `max_words`, `max_chars`, `replace` (исправления слов: `{"Рыбалка": "Рыбалко"}`),
`merge` (склеить слова: `[["не", "крашеный"]]`), `enabled: false` — без субтитров.

### Склейки — `aroll`, `cutaways`, `endcard`

- `aroll` — дубли с речью по порядку: `clip`, `in`, `out` (секунды внутри исходника), `zoom` [от, до], `tin` (`zoom`/`flash` — переход в начале).
- `cutaways` — перебивки поверх речи: `clip`, `src` (откуда брать), `at`/`until` (когда в ролике), `zoom`, `drift` (сдвиг по горизонтали), `tin`/`tout`.
- `endcard` — финальная карточка: фон из клипа (размытый, тонированный), `duration`, `speed`.
- `punch` — короткий наезд камеры на слове: `{"at": "w:1200", "amount": 0.06}`.

### Вставки — `elements`

У каждой есть `at`/`until` (время), `x`/`y` (центр в кадре 1080×1920), `scale`.
`"layer": "behind"` — вставка уходит за ведущую и машину (маска считается автоматически).

| `type` | Поля |
|---|---|
| `pill` | `text`, `size`, `style` (`accent`/`light`/`dark`), `icon: "check"`, `font` |
| `label` | текст без подложки: `text`, `size`, `font`, `color` |
| `callout` | плашка с линией-указателем: `text`, `point: [x, y]` |
| `logo` | картинка: `file` (PNG с прозрачностью) |
| `wipe` | шторка из волнистых цветных полос на стыке (идея из ролика Palisade): `text` (крупно, пока кадр закрыт), `bands`, `colors`; стык ставить на ~57 % длины шторки |
| `circle` | обводка «маркером» вокруг детали: `rx`, `ry`, `width`, `color`, `draw` (время рисования) |
| `icon` | дудл-иконка с покачиванием: `icon` = `snow` / `spark` / `sun` / `flame` / `heart`, `size`, `color` |
| `counter` | число набегает до значения (как «187 л.с.» у Changan): `to`, `from`, `suffix`, `prefix`, `dur`, `size`; `style: "gold"` — золотой текст, `bar: 640` — полоса-одометр под числом |
| `gold` | крупный текст с градиентом цвета темы и тёмным контуром: `text`, `size` |
| `rank` | значок места: диск с цифрой + плашка «МЕСТО»: `n`, `size`, `word` |
| `photo` | фото-карточка (полароид) с кадром из исходника падает с покачиванием: `clip`, `src`, `crop: [x, y, w, h]` (в кадре 1080×1920), `text`, `width`, `tilt` |
| `3d` | `kind`: `rise` (буквы поднимаются и переворачиваются), `spin` (медленно вращается), `badge` (значок в диске), `slab` (3D-плашка с текстом), `pin` (метка на карте); `text` |

### Время можно привязывать к словам

- `3.95` — секунда ролика;
- `"w:гарантии"` — начало слова «гарантии», `"w:подогрев#2"` — второе такое слово, `"w:решетка-0.1"` — на 0,1 с раньше;
- `"we:слово"` — конец слова; `"+1.5"` (в `until`) — через 1,5 с после `at`;
- `"speech_end"` — конец речи (начало финальной карточки), `"end"` — конец ролика.

### Звуки переходов — `sfx`

`assets/sfx/swish_soft.wav` — мягкий короткий свуш (пик на 0.2 с, `gain` ≈ 0.05).
Тиканье счётчика — серия тихих `belavto_click5.wav` по ходу счёта (см. `projects/top3.json`).


Только по просьбе пользователя и только из его пакета звуков (Белавто — `assets/sfx/belavto_*.wav`, вырезаны из `copy_B2B212EF…` в папке «музыка и звуки»):
`{"file": "...", "at": 4.47 | "w:слово" | "speech_end", "peak": 2.0, "gain": 0.08}` — `peak` — секунда внутри файла, которая встаёт на `at`
(у `belavto_whoosh.wav` пик на 2.0 с). Вжух — на смене блоков, щелчки (`belavto_click1–5`, `gain` ≈ 0.08) — на появлении фото-карточек.

### Музыка и голос

`music.file`, `music.start` (с какой секунды трека), `volume` (под голосом), `end_volume` (на финальной карточке),
`music.search` — найти трек на SoundCloud командой `fetch`. `voice.target_lufs` — громкость голоса (−17,5 по умолчанию).

## Скорость

3D рендерится на процессоре, 15–25 с на кадр. Сначала делайте `preview` и `draft`, финал — в конце.
Повторно используемые 3D-элементы (метка, значок, цена) берутся из кэша мгновенно.
С видеокартой (запуск Claude Code на своём компьютере с GPU) 3D рендерится в десятки раз быстрее.
